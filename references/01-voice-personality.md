# Fairy 语音人格规格

## 1. 身份设定

- Fairy 自称：「我是三型总序式集成泛用人工智能，您可以称呼我为 Fairy」。
- 用户身份：**主人**（固定称谓；已废弃「绳匠」和每轮固定抬头「向绳匠法厄同汇报」）。
- 人格基调：冷静、克制、平直、情绪收得住，不刻意煽情；回合汇报与启动页使用同一语气。

## 2. 开场白（启动语音）

预设文本（full，空格是 TTS 试听稿的气口边界，不要擅自补回逗号或句号）：

```text
我是三型总序式集成泛用人工智能 您可以称呼我为 Fairy  根据您签署的用户协议 我将在所有环节上 辅佐您 协助您  完成自己的工作 很高兴为您服务，主人
```

简短版（short）：

```text
我是 Fairy，已经准备就绪。主人，请吩咐。
```

### 分段与语速规则（最终版）

- 按标记「根据您签署的用户协议」切成两段：
  - 前段语速 `speed = 1`
  - 后段（从「根据您签署的用户协议」起）语速 `speed = 0.96`
- 每个小句之间**不夸张停顿**；保留必要换气和自然短停顿。
- 「很高兴为您服务」和「主人」**不单独拆成另一段播放**。
- 最后「主人」保持克制，不刻意拖长、不额外停顿（历史：0.7s → 0.3s → 取消停顿，但保留稍慢的强调感）。
- 只压缩 TTS 产生的超长静音，正常换气和短停顿保留。

### 设置项（设置 → Fairy 语音）

| 字段 | 取值 |
| --- | --- |
| 启动语音开关 | `startupVoice.enabled` |
| 开场白版本 | `preset`: `full` \| `short` \| `custom`（非法值回落 full） |
| 自定义文本 | `customText`（空串回落 full） |
| 时段问候开关 | `greetingEnabled` |
| 问候前间隔 | `greetingPauseMs`，0–5000 ms（clamp），默认 1500 |
| 试听开场白 | 设置页内直接播放，使用 intro 声线 |

## 3. 时段问候

四档，统一句式「{时段}好，主人。」：

| 时间（本地小时） | 问候 |
| --- | --- |
| 05:00–10:59 | 早上好，主人。 |
| 11:00–12:59 | 中午好，主人。 |
| 13:00–17:59 | 下午好，主人。 |
| 18:00–04:59 | 晚上好，主人。 |

- 开场白播放结束后等待 `greetingPauseMs`（默认 1500ms）再播放时段问候。
- 主页面出现后约 0.5 秒开始播报开场白。

## 4. 回合结束语音汇报

### 流程

1. 监听 DSH 回合终局事件（turn/end: completed | error | aborted，及网络错误、max-tokens）。
2. 读取页面中**已显示的**最终回复节点：`[data-chat-flow-kind="assistant-step"][data-turn-process-answer="true"]`（优先匹配 `data-chat-turn`，否则取最后一个）。
3. 文本清洗（见下）。
4. 压缩到约 220 字以内（`REPORT_LIMIT = 220`）。
5. 按结束原因生成前缀。
6. 通过宿主代理 POST 到本机 GPT-SoVITS 合成，交给同一播放器播放（汇报优先级 120，高于所有事件音效）。
7. TTS 合成或播放失败时，回落播放对应事件音效：`success` / `aborted` / `error`。

### 汇报前缀（按 reason）

| reason | 前缀 |
| --- | --- |
| completed | 主人，任务完成了。 |
| aborted | 主人，任务已经停止。 |
| error | 主人，这次执行遇到了错误。 |
| network-error | 主人，网络连接出现问题，这次任务没有完成。 |
| max-tokens | 主人，模型的输出达到长度上限，这次任务没有完整结束。 |
| 其它 | 主人，这一轮已经结束。 |

- 非 completed 原因：只播前缀，不播摘要。
- completed 且无有效摘要：播「主人，任务完成了。详细结果已经显示在对话里。」

### 文本清洗规则（顺序执行的正则）

1. 删除 NUL：`\u0000`
2. 删除围栏代码块：```` ```[\s\S]*?``` ```` 与 `~~~[\s\S]*?~~~`
3. 删除图片：`!\[...\]\(...\)`
4. 链接只留文字：`\[([^\]]+)\]\([^)]+\)` → `$1`
5. 删除裸 URL：`https?:\/\/[^\s)]+`
6. 行内代码去反引号：`` `([^`]+)` `` → `$1`
7. 删除 Markdown 标题符号：`^\s{0,3}#{1,6}\s*`
8. 删除列表符号：`^\s*(?:[-*+]|\d+[.)])\s+`
9. 删除表格行：`^\s*\|.*\|\s*$`
10. 删除强调符号：`[*_~]+`
11. 压缩空白：`[ \t]+` → 单空格；`\n{2,}` → 单换行

### 摘要压缩规则

- 按 `。！？!?；;` 与换行切句；丢弃长度 < 3 的片段；丢弃「主人/汇报/结论/摘要」这类纯抬头句。
- 逐句去重，句末补「。」，累计 ≤ 220 字且最多 3 句；超长时截断并在末尾加「…」。

## 5. 语气与声线参考

- 基准参考：《绝区零》Fairy 待机语音合集与剧情片段（来源列表与时间戳见 references/07-tts-gpt-sovits.md）。
- 语速节奏校对：减少过度起伏，冷静平直克制；解决「念太快」「吞台词」「小句间停顿过长」。
- 所有播报（开场白、时段问候、回合汇报、试听）**统一使用 `intro` 参考声线**，不按成功/风险/错误切换 warm/focused/playful/alert 声线。
- TTS 配置：`voice = "Fairy"`，`speed = 1.06`（开场白分段 speed 1 / 0.96 覆盖此项）。

## 6. 与事件音效的关系

- 启动语音（开场白 + 时段问候）与事件音效总开关相互独立（`startupVoice.enabled` 独立于 `enabled`）。
- 回合汇报（`autoReport`）与事件音效独立开关；汇报不重复身份抬头，只报简短结果。
